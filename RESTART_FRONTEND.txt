🔄 CẦN RESTART FRONTEND!

Vì đã sửa file setupProxy.js, bạn CẦN RESTART frontend để thay đổi có hiệu lực.

📝 Các thay đổi:
1. ✅ Đổi từ 'localhost' → '127.0.0.1' (để dùng IPv4 thay vì IPv6)
2. ✅ Fix message lỗi từ port 3001 → 3000

🔧 Cách restart:
1. Tắt terminal frontend (Ctrl+C)
2. Chạy lại: npm start

hoặc

1. Tắt cả 2 terminal
2. Chạy: npm run dev:all

✅ Sau khi restart, frontend sẽ kết nối được với backend!
