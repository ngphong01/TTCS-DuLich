# Frontend React SPA

## Khởi động
```bash
cd frontend
npm install
npm start
```

- Sử dụng React Router SPA (tất cả route mapping sang component tương ứng trong App.tsx)
- Mọi fetch dữ liệu gọi đến backend Express (`http://localhost:3001/api/...`)
- Styles bằng Tailwind, file config đã chuẩn React

## Customize thêm chỉ cần chỉnh App.tsx, thêm route mới, hoặc component vào folder `/components`, `/account`, ...
